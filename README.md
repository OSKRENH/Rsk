# РСК · Бренд-центр

Современный лендинг и бренд-портал на основе визуального языка https://rsk-development.ru.

Разделы: логотип, цифровая палитра, интерактивный образец Golos Text, шесть проектов с фильтрами и просмотром рендеров, комплекты файлов.

## Дизайн и взаимодействия

Фирменные Golos Text и голубая палитра, полноэкранный голубой первый экран, полупрозрачная навигация и адаптивные поверхности. Подход `apple-design`: отклик при нажатии, пружинный просмотр проектов без отскока, обратимый путь закрытия и поддержка reduced motion/transparency и повышенного контраста.

## Проверка и публикация

- `npm run check`: проверка JavaScript, файлов и ссылок внутри страницы.
- Каталог публикации: `dist`. Сборка без зависимостей.
- Cloudflare Workers: `npm run deploy` после подключения аккаунта. Конфигурация `wrangler.jsonc`, имя Worker `rsk`.
- Cloudflare Workers Builds: подключите `OSKRENH/Rsk`, ветка `main`, build command `npm run build`, deploy command `npx wrangler@4 deploy`. Корень проекта `/`.
- Cloudflare Pages: build command `npm run build`, output directory `dist`.

## Источники

- Веб-шрифты и превью проектов: официальный сайт РСК, 10.10.2026. Точные источники в `dist/sources.json`.
- Дополнительные рендеры: https://disk.yandex.ru/d/Vznzzq6ocT7DKA, доступность шести папок проверена.
- TTF Golos Text и лицензия OFL: https://github.com/google/fonts/tree/main/ofl/golostext.

Логотип извлечён из приложенного `Рабочие_файлы_РСК.ai`: крупная горизонтальная версия с трёхстрочным дескриптором. Цветной вариант сохраняет исходный голубой #72C6EF; белый и чёрный используют ту же векторную геометрию и прозрачные буквы. Все версии доступны отдельно и в ZIP. Интерфейс использует один фирменный голубой, без прежнего #00A7FF.

Альтернативный наклонный знак без дескриптора взят из Figma-гайдбука РСК, узлы `25:586`, `29:736`, `29:747`. Три оригинальных SVG-экспорта сохранены без изменений, доступны отдельно и в общем ZIP с основными версиями.

Раздел логотипов содержит ровно три карточки: полный, без дескриптора и альтернативный. Внутри каждой независимые цветовые кружки как в бренд-центре Эталона; SVG скачивается в выбранном цвете. Компактные белая и чёрная версии сохраняют геометрию исходного знака.
