# РСК · Бренд-центр

Современный лендинг и бренд-портал на основе визуального языка https://rsk-development.ru.

Разделы: логотип, цифровая палитра, интерактивный образец Golos Text, шесть проектов с фильтрами и просмотром рендеров, комплекты файлов.

## Дизайн и взаимодействия

Бренд без изменений: логотипы, голубой #72C6EF, Golos Text, структура и тексты. Новый язык: крупная типографика, асимметричные блоки (логотипы, палитра, мозаика проектов), фото проектов, выходящие из голубой обложки, один тёмный блок для шрифта и второй голубой блок для файлов. Единая система форм: контейнеры 28 px, кнопки и фильтры в виде пилюль. Только Golos Text Regular и Medium (SemiBold и Bold в интерфейсе не загружаются). Движение: появление блоков при прокрутке через IntersectionObserver, пружинный просмотр проектов, поддержка reduced motion/transparency и повышенного контраста.

## Проверка и публикация

- `npm run check`: проверка JavaScript, файлов и ссылок внутри страницы.
- Каталог публикации: `dist`. Сборка без зависимостей.
- Cloudflare Workers: `npm run deploy` после подключения аккаунта. Конфигурация `wrangler.jsonc`, имя Worker `rsk`.
- Cloudflare Workers Builds: подключите `OSKRENH/Rsk`, ветка `main`, build command `npm run build`, deploy command `npx wrangler@4 deploy`. Корень проекта `/`.
- Cloudflare Pages: build command `npm run build`, output directory `dist`.

## Источники

- Веб-шрифты и превью проектов: официальный сайт РСК, 10.10.2026. Точные источники в `docs/sources.json` (вне публичной папки).
- Дополнительные рендеры: https://disk.yandex.ru/d/Vznzzq6ocT7DKA, доступность шести папок проверена.
- TTF Golos Text и лицензия OFL: https://github.com/google/fonts/tree/main/ofl/golostext.

Логотип извлечён из приложенного `Рабочие_файлы_РСК.ai`: крупная горизонтальная версия с трёхстрочным дескриптором. Цветной вариант сохраняет исходный голубой #72C6EF; белый и чёрный используют ту же векторную геометрию и прозрачные буквы. Все версии доступны отдельно и в ZIP. Интерфейс использует один фирменный голубой, без прежнего #00A7FF.

Альтернативный наклонный знак без дескриптора взят из Figma-гайдбука РСК, узлы `25:586`, `29:736`, `29:747`. Три оригинальных SVG-экспорта сохранены без изменений, доступны отдельно и в общем ZIP с основными версиями.

Раздел логотипов содержит две карточки: полный логотип (с переключателем дескриптора) и альтернативный. Внутри каждой независимые цветовые кружки; SVG скачивается в выбранном цвете.

Основной логотип имеет переключатель «Дескриптор»: надпись выезжает вправо из прямоугольного знака и уезжает обратно влево, а знак встаёт по центру. Скачивается тот вариант, который показан: полный логотип или знак без дескриптора (в выбранном цвете).

Карта городов РСК взята из блока «География проектов» на главной странице https://rsk-development.ru (`/assets/images/icons/custom-map-modern.svg`). В конце страницы доступна для скачивания в SVG и PNG (2x). Источник записан в `docs/sources.json` (вне публичной папки).

## Структура репозитория

- `dist/` публичная папка (Cloudflare Workers assets). `_headers` задаёт CSP, безопасность и кэш.
- `source-assets/` исходные крупные изображения и шрифты, не публикуются.
- `docs/` внутренние заметки об источниках, не публикуются.
- Карта для мобильного (`dist/assets/rsk-map-compact.svg`) собрана из основной карты с увеличенными маркерами.
- `og:image` задан относительным путём `assets/og.png`. После привязки домена замените на абсолютный адрес и добавьте `canonical`.

## Проверки

- `npm run check`: синтаксис JS, баланс тегов, якоря, файлы и `srcset`, шесть проектов, шрифты, JSON-LD и хеши inline-скриптов в CSP из `dist/_headers`.
- Адрес сайта в `og:url`, `og:image`, `canonical`, `sitemap.xml` и `robots.txt` указан как `https://rsk.ivankamaldinov.workers.dev/`. При смене домена замените его во всех четырёх местах.

## Обложка

Фон первого экрана медленно колышется, как флаг: `dist/flag.js` рисует на WebGL ткань со складками. Средний цвет остаётся фирменным `#72C6EF`, складки лишь на несколько процентов светлее или темнее. Без WebGL остаётся плоский голубой, при `prefers-reduced-motion` рисуется один неподвижный кадр, вне экрана и в фоновой вкладке отрисовка останавливается.
